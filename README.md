# Русский язык · ОГЭ 2026 — тренажёр всех заданий (9 класс)

**▶ Демо: https://andreycoderr.github.io/russian-oge-2026/**

Интерактивный тренажёр по русскому языку для подготовки к **ОГЭ 2026** —
покрывает **все задания экзамена с 1-го по 13-е** в формате демоверсии ФИПИ.
Сделан в стиле проекта «Учительская» (Арина Галицкая): современный дизайн
с анимациями, геймификацией и тёмной/светлой темой.

Структура сверена по демоверсии, спецификации и кодификатору **ОГЭ-2026**
(fipi.ru). Объяснения сверены по справочникам Розенталя, «Русскому
орфографическому словарю» РАН и толковым словарям. В ОГЭ **нет** заданий
на ударение (орфоэпию) и паронимы — это задания ЕГЭ.

## Что внутри

**13 станций = 13 заданий ОГЭ, 144 вопроса с разбором.** Одна станция — одно задание:

| № | Станция | Что тренируем |
|---|---------|---------------|
| 1 | Сжатое изложение | приёмы сжатия, 3 микротемы, критерии ИК1–ИК3 (теория) |
| 2 | Синтаксический анализ: грамматическая основа | нахождение подлежащего и сказуемого |
| 3 | Синтаксический анализ предложения | характеристика: цель, структура, типы |
| 4 | Пунктуационный анализ | объяснение знаков: запятая, тире, двоеточие |
| 5 | Знаки в сложных конструкциях | пунктуация в ССП / СПП / БСП и при оборотах |
| 6 | Орфографический анализ | выбор верного объяснения написания |
| 7 | Правописание: пропущенные буквы | корни, приставки, суффиксы, окончания, Н/НН, НЕ |
| 8 | Грамматические нормы | нормативное образование форм слова |
| 9 | Синонимия словосочетаний | согласование ↔ управление ↔ примыкание |
| 10 | Смысловой анализ текста | верные / неверные утверждения по содержанию |
| 11 | Средства выразительности | эпитет, метафора, олицетворение, сравнение, фразеологизм |
| 12 | Лексический анализ слова | синонимы, антонимы, фразеологизмы, значение, стилистика |
| 13 | Сочинение: теория и критерии | 13.1 / 13.2 / 13.3, критерии СК1–СК4 (теория) |

> ОГЭ-2026: 13 заданий, 3 части, макс. **37 первичных баллов**, 235 минут.
> Изложение — до 6 баллов, задания 2–12 — по 1 баллу, сочинение — до 7 баллов,
> грамотность (ГК1–ГК4 + ФК1) — до 13 баллов по изложению и сочинению совокупно.

## Как это работает

- **Карта квеста** с анимированным прогрессом и общим рангом (от «Начало пути» до «Магистр слова»).
- **144 вопроса** на 13 станциях, каждый — с разбором правила в стиле ОГЭ.
- **Геймификация:** звёзды за ответы, серии (🔥), всплывающее «+1», конфетти за хороший результат.
- **Настраиваемый порог открытия станций:** 50% / 60% / 70% / «все звёзды».
  Следующая станция открывается, только если набран выбранный порог.
- **Кнопка учителя:** по коду открывается доступ ко всем станциям сразу.
- На каждый вопрос **сразу видно**, верно или нет, и **правило-объяснение**.
- **Финал и грамота:** после прохождения всех 13 станций открывается именная грамота
  «Русский язык. ОГЭ 2026» — с рангом, числом звёзд и датой.
- **Экспорт результата для репетитора:** текстовый отчёт, грамота картинкой (PNG) или
  отправка в Telegram.
- **Рекомендации и разбор ошибок:** темы от слабых к сильным, пометка «приоритет» при <70%.
- Прогресс **сохраняется в браузере** (localStorage). Управление с клавиатуры: **Enter / →**.

## Запуск

Чистый статический сайт без сборки. Достаточно открыть `index.html`
или опубликовать папку на GitHub Pages.

```
russian-oge-2026/
├── index.html   — разметка
├── styles.css   — оформление (тёмная + светлая тема)
├── data.js      — все задания 1–13 и объяснения
├── app.js       — логика квеста
└── README.md
```

## Как добавить задания

Открой `data.js` и допиши вопрос в нужную станцию:

```js
{
  q: "Текст вопроса (можно с <b>выделением</b>).",
  passage: "Необязательный текст-пример (для заданий с текстом).",
  options: ["вариант 1", "вариант 2", "вариант 3", "вариант 4"],
  answer: 0,            // индекс правильного варианта в исходном порядке
  explain: "Объяснение правила, которое покажется после ответа."
}
```

Варианты (2 — крупные плитки, 4 — список) и порядок вопросов перемешиваются
автоматически, поэтому `answer` всегда указывает на правильный вариант
в исходном порядке. Счётчики на главной (число вопросов и звёзд) считаются
из `data.js` динамически.
